# 🧠 Agentic AI Content Companion

A mood-aware, platform-specific content planning assistant built with Streamlit.  
Designed to help creators and entrepreneurs generate ideas, motivational quotes, and schedule content based on emotional state and platform focus.

## 🚀 Features

- 🎯 Mood-based theme selection (focused, inspired, tired, blank, and more)
- 📝 Content idea generation for TikTok and LinkedIn
- 💬 Motivational quote delivery
- 📅 Calendar scheduling with status tracking
- 📊 Google Sheets export integration
